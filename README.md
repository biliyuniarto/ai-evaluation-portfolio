## Core evaluation dimensions

1. **Instruction adherence** — Does the response satisfy every explicit constraint?
2. **Factuality** — Are its claims supported, accurate, and appropriately qualified?
3. **Utility** — Does it help the user make progress or complete the task?
4. **Naturalness** — Does the wording sound fluent and context-appropriate in Indonesian?
5. **Conversational dynamics** — Does the assistant respond directly, maintain context, and avoid unnecessary friction?
6. **Audio quality** — For spoken interactions, are pacing, pronunciation, intonation, and turn-taking clear and natural?

## Method

For each evaluation, I:

1. Extract the explicit instructions and implied user goal.
2. Identify any facts that require verification or qualification.
3. Score each response independently using the same criteria.
4. Compare both responses dimension by dimension.
5. Select the stronger response only when the evidence supports a preference.
6. Write a concise rationale that explains both strengths and weaknesses.
