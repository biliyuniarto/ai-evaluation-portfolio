03 / Evaluation method

A repeatable path from prompt to verdict.

Style alone should not decide a preference. I separate material errors from subjective differences and compare both responses on the same dimensions.

  1. 01

    Extract

    Map explicit constraints, implied intent, audience, and risk.

  2. 02

    Inspect

    Check facts, unsupported certainty, and instruction gaps.

  3. 03

    Score

    Evaluate each response independently using identical criteria.

  4. 04

    Compare

    Make the judgment dimension by dimension, apple to apple.

  5. 05

    Explain

    Write a concise rationale grounded in observable evidence.
